Enunciados

O número de parada não conta: o range vai até fim - 1.

Lógica de Progamação com Python

!!! Anotação !!!

Exemplo 1

range(1, 9)

Escreva um programa em Python que use a estrutura for para exibir a mensagem "Aluno" seguida do número de cada aluno, de 1 até 8..

for aluno in range(1, 9):
    print("Aluno", aluno)

Exemplo 2

range(2, 21, 2)

O step de 2 Escreva um programa em Python que use a estrutura for para exibir apenas os números pares de 2 até 20, com a mensagem "Número par" antes de cada valor.

for numero in range(2, 21, 2):
    print("Número par", numero)

Resumo: range(inicio, fim, step) vai de inicio até fim - 1, andando de step em step. Para incluir o último valor desejado, o limite deve ser maior que ele.
